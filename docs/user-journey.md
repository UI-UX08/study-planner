JOURNEY 1: ALEX KIPROP | 3RD YEAR COMPUTER SCIENCE
================================================================================
Scenario:
Alex overestimates his evening availability and misses a scheduled software design task 
due to an extended offline developer bootcamp. He requires an automated, low-friction 
recovery path to adjust his schedule without manual recalculation.

Stage 1: Pre-Execution State (View Reminders & Dashboard Navigation)
  - User Action: Launches the application and navigates to the primary dashboard 
    via the bottom navigation bar to review his evening schedule.
  - System Response: Renders a personalized daily view featuring color-coded course 
    tags (#CS301) and high-contrast urgency indicators.
  - HCI Principle: Executive Dashboards & Personalization
  - Behavioral State: Focused | Cognitive Load: Low

Stage 2: Operational Disruption (Event Trigger)
  - User Action: Remains at the coding bootcamp past 19:00, failing to initiate 
    his scheduled Java module task.
  - System Response: System background monitor detects an unfulfilled task state 
    exceeding its temporal window without user intervention.
  - HCI Principle: Adaptive Interaction & State Tracking
  - Behavioral State: Anxious | Cognitive Load: Moderate

Stage 3: Proactive System Intervention (Notifications & Control)
  - User Action: Receives an actionable push notification on his mobile lock screen.
  - System Response: Dispatches a polite, non-intrusive alert: "Missed your 19:00 
    Java block? Tap to auto-reschedule or preserve for manual review."
  - HCI Principle: Actionable Notifications & User Control
  - Behavioral State: Reassured | Cognitive Load: Minimal

Stage 4: Automated Schedule Adaptation (Reschedule Missed Tasks)
  - User Action: Selects the notification and taps "Auto-Reschedule to Next Available Window".
  - System Response: Re-evaluates Alex's user-defined availability matrix, 
    reallocating the 2-hour task to an uncommitted morning slot.
  - HCI Principle: Adaptive Interaction & Error Recovery
  - Behavioral State: Relieved | Cognitive Load: Low

Stage 5: State Reconciliation & Confirmation (System Feedback)
  - User Action: Inspects the updated morning timeline on his primary dashboard.
  - System Response: Displays a brief tactile and visual confirmation toast ("Schedule 
    successfully rebalanced") and updates his daily workload distribution metric.
  - HCI Principle: Immediate Feedback & System Visibility
  - Behavioral State: Motivated | Cognitive Load: Zero
